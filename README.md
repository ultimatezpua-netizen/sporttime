Garmin Sport Time 🏃‍♂️⌚
Мобильное приложение для просмотра каталога спортивных часов Garmin, взаимодействия с интерактивным симулятором смарт-устройств и оформления заказов.

📱 Основные возможности
Каталог и поиск: Просмотр моделей Garmin (Fēnix, Forerunner, Edge и др.) с фильтрацией и сортировкой.

Интерактивный симулятор: Эмуляция экрана часов (циферблат, режим компаса, параметры тренировки, пульс) с поддержкой жестов.

Карточка товара: Выбор модификаций (размер корпуса, цвет, материал стекло/титан), галерея изображений и характеристики.

Оформление заказа: Интеграция с доставкой Новой Почты (выбор города, отделения) и вариантами оплаты.

🛠 Технологический стек
Фреймворк: React Native + Expo (SDK 54)

Язык: TypeScript

Навигация: Expo Router

Пакетный менеджер: pnpm (Monorepo Workspace)

🚀 Быстрый запуск
Требования
Node.js (v18+)

pnpm (npm i -g pnpm)

Установка зависимостей
Bash
# Клонирование репозитория
git clone https://github.com/ultimatezpua-netizen/sporttime.git
cd sporttime

# Установка всех пакетов
pnpm install
Запуск в режиме разработки
Bash
# Запуск через Expo
pnpm exec expo start
📦 Локальная сборка Android (Release APK)
Генерация нативного проекта и компиляция релиза:

Bash
# 1. Пересборка нативных директорий Expo
pnpm exec expo prebuild --platform android --clean

# 2. Компиляция APK
cd android && ./gradlew assembleRelease
Готовый файл APK будет находиться по пути:
android/app/build/outputs/apk/release/app-release.apk
